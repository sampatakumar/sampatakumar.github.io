## 🌟 Overview

This repository holds the **Next.js App Router** edition of **Sampatakumar V's** personal developer portfolio. Built as an Awwwards-inspired, dark-themed editorial website, it combines cinematic GSAP animations, virtual momentum scrolling via Lenis, interactive case studies, and complete accessibility with a zero-compromise performance budget.

## 🏗️ 12 Core Implemented Sections

1. **Preloader:** Minimalist full-screen loading sequence with animated 0–100% progress counter and smooth clip-path curtain exit.
2. **Navigation:** Fixed backdrop-blur navbar with active section pills, live availability HUD indicator, and full-screen mobile menu.
3. **Cinematic Hero:** Expressive oversized headline with GSAP word-by-word reveal, live Bengaluru coordinates, authentic portrait, and primary CTAs.
4. **The Person Behind The Code (About):** Editorial split narrative highlighting B.E. Computer Science Engineering studies at Rajiv Gandhi Institute Of Technology (RGIT), 4 engineering pillars, and published research.
5. **Selected Work (Projects):** Large featured card showcase with hover image scaling, real metrics tags, live demos, and case study links.
6. **Flagship Capstone Case Study:** Interactive architectural blueprint of **Smart Skill Hub (SSH)** detailing all 7 system tiers from React client to isolated Docker container sandbox.
7. **Technical Arsenal:** Categorized technology grid across Frontend, Backend, Databases, AI, DevOps, and Creative Development without fabricated percentages.
8. **The Journey (Timeline):** Verified vertical timeline tracking degree studies, peer-reviewed IRE Journals publication (ISSN: 2456-8880), and engineering milestones.
9. **GitHub Activity (Open Source):** Live telemetry showcasing 20+ public repositories, verified language breakdown (52% TypeScript, 38% JavaScript, 10% CSS/HTML), and profile CTA.
10. **Currently Exploring:** Animated grid detailing active research into Agentic AI, React Native, Canvas/WebGL motion, and container sandboxing.
11. **Contact & Collaboration:** Direct channels with 1-click email copy, WhatsApp chat, verified resume PDF download, and interactive student project collaboration pitch modal.
12. **Editorial Footer:** Personal wordmark, navigation links, verified socials, and smooth back-to-top interaction.

## 💻 Local Development

### 1. Prerequisites
- **Node.js** v18.18+ or v20+
- **npm** v9+

### 2. Setup
```bash
# Clone or switch to vercel branch
git clone -b vercel https://github.com/sampatakumar/sampatakumar.github.io.git
cd sampatakumar.github.io

# Install dependencies
npm install

# Run development server with Hot Module Replacement
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Production Build
```bash
# Generate optimized production build
npm run build

# Start local production server
npm start
```

## ☁️ Vercel Deployment

1. Go to [Vercel Dashboard](https://vercel.com/new).
2. Select your repository `sampatakumar/sampatakumar.github.io`.
3. In the **Production Branch** setting, select `vercel`.
4. (Optional) Set `MONGODB_URI` environment variable if you wish to persist collaboration form submissions to MongoDB Atlas.
5. Click **Deploy**. Vercel will automatically detect Next.js and deploy your cinematic portfolio.
